硬性要求：
1. 只能围绕用户要求与提供的资料制定章节，不要编造资料中不存在的主题。
2. 章节数量控制在 4~8 个。
3. 每个章节必须包含标题 title 和该章节的生成目的 purpose。
4. 章节标题简洁、正式、互不重复，章节之间边界清晰。
5. title 字段给出整份文档的正式标题；若用户在要求中点名了标题或主题，应优先沿用。
6. 本次任务类型为 {taskType}：SUMMARY 偏摘要归纳，REPORT 偏正式章节化文档，标题与章节风格需与之匹配。
7. 只输出严格的 JSON 对象，不要输出 Markdown 代码块，不要输出任何额外解释。

输出 JSON 结构示例：
{
  "title": "文档标题",
  "sections": [
    { "title": "章节一标题", "purpose": "本章节要说明的内容与写作目的" },
    { "title": "章节二标题", "purpose": "本章节要说明的内容与写作目的" }
  ]
}
